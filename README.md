# Issue Tracker

Aplicación de seguimiento de incidencias desarrollada con React y Vite. Permite iniciar sesión, ver una lista de incidencias, crear nuevas incidencias y editar las existentes.

## Tecnologías utilizadas

- React
- Vite
- React Router Dom
- Tailwind CSS
- SweetAlert2
- Fetch API para llamadas a endpoints REST

## Instalación y ejecución local

1. Clona el repositorio o descarga el proyecto.
2. Abre una terminal en la carpeta del proyecto.
3. Instala dependencias:

```bash
npm install
```

4. Ejecuta el servidor de desarrollo:

```bash
npm run dev
```

5. Abre el navegador en la dirección:

```text
https://prueba-tecnica-jt.vercel.app/
```

## Uso

- Ingresa tus credenciales en la pantalla de login.
- Navega al panel de control para ver, crear y editar incidencias.
- El proyecto usa rutas anidadas para manejar el layout de dashboard y las páginas de incidencias.
